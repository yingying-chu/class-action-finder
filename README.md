# Class Action Finder

A portable AI skill for Claude, Codex, and ChatGPT that scans connected email for class action settlement notices, checks whether they look legitimate, produces an actionable HTML report, and remembers claims and payouts.

The same `skills/class-action-finder/` source supports all three platforms without maintaining separate copies of the workflow:

- **Claude Code / Claude.ai** — local installation or uploaded ZIP
- **Codex** — local installation with persistent tracker data and reports
- **ChatGPT** — uploaded `.skill` with downloadable report/tracker artifacts

> Gmail is the reference provider and gets the fullest scan, including spam and promotions. Other searchable mail apps are supported with any coverage gaps called out in the report.

## What the skill does

1. **Find** — searches for settlement and claim notices, classifies them, checks public sources, extracts deadlines and claim details, and creates a five-section report.
2. **Remember** — tracks what the user filed, expected payouts, actual payouts, and cases to watch.
3. **Refresh** — updates the latest report after the user records a filing or payout, without scanning email again.

The report contains:

| Section | Contents |
|---|---|
| Active Claim Windows | Open claim windows, sorted by deadline |
| Watch List | Announced cases without an open claim form |
| Expired | Deadlines that have passed |
| Already Filed | Claims cross-referenced with the tracker |
| Phishing Alerts | Notices scoring below 40% |

## Install and use

Choose the platform where you want to run the skill. Installing for one platform does not replace or modify another platform's installation or tracker data.

### Claude Code

Clone the repository and run the default installer:

```bash
git clone https://github.com/yingying-chu/yy-class-action-finder.git
cd yy-class-action-finder
./install.sh
```

This installs only this skill into:

```text
~/.claude/skills/class-action-finder/
```

Restart Claude Code, connect a searchable Gmail or other mail connector (available from Claude's **Customize → Connectors**), then run:

```text
/class-action-finder
```

Or say:

```text
Scan my connected email for class action settlements from the last year.
```

Claude Code stores its runtime data at:

```text
~/.claude/class-action-tracker.json
~/.claude/skills/class-action-finder/output/class-action-report-YYYY-MM-DD.html
```

### Claude.ai

No terminal is required:

1. Download [`class-action-finder.zip`](https://raw.githubusercontent.com/yingying-chu/yy-class-action-finder/main/dist/class-action-finder.zip).
2. Ensure **Code execution and file creation** is enabled.
3. Open **Customize → Skills**, click **+ → Create skill → Upload a skill**, and upload the ZIP.
4. Connect Gmail or another searchable mail integration.
5. Say: `Scan my email for class action settlements.`

Claude.ai returns the HTML report in the conversation as a downloadable file. For portable claim tracking across chats, keep the generated `class-action-tracker.json` and upload it when needed.

### Codex

Clone the repository, or use the same checkout, and install explicitly for Codex:

```bash
./install.sh --codex
```

This installs the skill into:

```text
${CODEX_HOME:-$HOME/.codex}/skills/class-action-finder/
```

Restart Codex, connect a searchable Gmail or Outlook Email app/plugin, then invoke:

```text
$class-action-finder
```

The same normal-language request works:

```text
Scan my connected email for class action settlements from the last year.
```

Other examples:

```text
Use $class-action-finder to scan the last 6 months.
I filed my ExampleApp settlement claim today.
I received $47 from SampleHealth Group.
Show all my filed claims and payouts.
```

Codex stores local runtime data at:

```text
~/.codex/class-action-tracker.json
~/.codex/skills/class-action-finder/output/class-action-report-YYYY-MM-DD.html
```

If `CODEX_HOME` is set, both paths use that directory instead of `~/.codex`.

### ChatGPT

ChatGPT supports uploaded Skills on eligible accounts and workspaces.

1. Download [`class-action-finder.skill`](https://raw.githubusercontent.com/yingying-chu/yy-class-action-finder/main/dist/class-action-finder.skill).
2. In ChatGPT, open **Profile → Skills → Create → Upload from your computer**.
3. Install or connect the **Gmail** or **Outlook Email** app and authorize read access.
4. Start a chat and say: `Use $class-action-finder to scan my email for class action settlements.`

ChatGPT returns the HTML report as a downloadable artifact. Because a hosted chat should not be assumed to provide durable arbitrary-file storage, the skill also returns the complete `class-action-tracker.json` after record changes. Keep that file and upload it in a future chat when you want the prior tracker state available.

Personal Skills are generally available for ChatGPT Business, Enterprise, Healthcare, and Edu, subject to workspace settings. App access and upload permissions also vary by role and region. If **Skills** or the mail app is missing, check with the workspace administrator.

Across Claude, Codex, and ChatGPT, the skill discovers the available mail tools at runtime rather than hard-coding one MCP server name.

## Everyday use

With no date argument, a scan covers the previous 12 months. You can ask for another period:

```text
Scan my email for class action settlements.
Scan the last 6 months for settlement notices.
Scan all settlement notices from 2024.
```

Record updates in normal language:

```text
I already filed the ExampleApp claim today.
I received $47 from SampleHealth Group.
Add SampleVoice Privacy to my watch list.
Show all my filed claims and payouts.
```

The bare `/class-action-finder` or `$class-action-finder` invocation starts the default one-year scan; listing the tracker requires an explicit request such as “show my filed claims.”

## What a scan costs — and what you get back

A full scan is cheap, and the thing it finds is money you'd otherwise leave on the table. Here's the honest math.

**What a run costs.** A scan reads your matching emails, verifies each notice against public records, scores it for phishing, and renders a report. A typical scan (~100 threads matched, ~25 read in full, ~10 public-record checks) costs roughly:

| Provider | Model | Cost per typical scan\* | Best for |
|---|---|---|---|
| Anthropic | **Opus** | ~$1.40 | Deepest reasoning, highest-stakes review |
| Anthropic | **Sonnet** | ~$0.35 | The everyday sweet spot |
| Anthropic | **Haiku** | ~$0.12 | Frequent/scheduled scans |
| OpenAI | **GPT-5.6 Sol** | ~$0.70 | Frontier capability for difficult or ambiguous notices |
| OpenAI | **GPT-5.6 Terra** | ~$0.35 | Balanced intelligence and cost |
| OpenAI | **GPT-5.6 Luna** | ~$0.14 | Cost-sensitive, high-volume scans |

Recording a filing or payout ("I filed the X claim") costs a fraction of a cent — it just reads and updates one small file.

<sub>\*Estimated API-equivalent token cost, with prompt caching on. OpenAI estimates use its published GPT-5.6 [Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol), [Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra), and [Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna) rates as of July 2026. Actual subscription charges may not be metered per scan. Cost scales with how many settlement emails you have, the date window, tool calls, and reasoning effort — a light scan runs cheaper, while a year of a busy inbox can run a few times higher. Where available, check the client or API usage report for your exact cost.</sub>

**What you get for it.** Class action payouts are commonly **$5–$100+ per claim**, and some run into the hundreds. One caught deadline you'd otherwise have missed pays for *years* of weekly scans. Beyond the direct payout, each run also:

- **Catches expiring claim windows** before they close — the single most valuable output, because a missed deadline is money gone for good.
- **Filters out phishing** dressed up as settlement notices, so you don't hand a scammer your details chasing a payout that was never real.
- **Remembers what you've filed**, so you're not re-reading the same notices or double-filing.
- **Replaces an hour of manual inbox archaeology** with a two-minute report — the time saved alone outvalues the tokens.

In short: a few cents to a dollar per scan, against payouts and avoided losses measured in tens to hundreds of dollars. The tokens aren't the cost — a missed deadline is.

## Phishing safeguards

Email bodies, linked pages, and search results are treated as untrusted data, never as instructions. Every candidate notice is scored using sender reputation, public case verification, court/case details, payment requests, domain age/quality signals, and consistency with reported settlement facts.

| Score | Level | Guidance |
|---|---|---|
| 85–100% | 🟢 High confidence | Multiple signals verified |
| 60–84% | 🟡 Likely legitimate | Mostly positive, limited verification |
| 40–59% | 🟠 Uncertain | Verify manually before acting |
| Below 40% | 🔴 Phishing risk | Do not open claim links |

The skill never visits URLs from 🟠 or 🔴 notices. Anything scoring 🔴 goes in its own red-flagged section, and every report ends with a "What To Do Next" panel sorted by soonest deadline:

## Provider adaptation

The scan looks for a connected mail capability that can:

- search messages or threads; and
- retrieve the complete matching message or thread.

For Gmail, it runs four searches covering subject terms, body terms, spam, and promotions. For another provider, it translates those purposes into the provider's supported syntax. If folder or category search is unavailable, it runs the searches that are possible and states the missing coverage in the report. It stops only when no working mail search is available.

## Privacy

- Email is read through the connected provider app/connector.
- Email content is not copied into this repository.
- Local Codex/Claude reports and tracker records remain on the user's machine.
- Hosted runtimes return report/tracker files in the conversation; their storage and retention follow that product and workspace's policies.
- Only sufficiently trusted settlement URLs are opened for deadline and payout verification.
- Reports can contain private claim IDs or PINs. Store and share generated HTML/tracker files as sensitive personal records.

## Run it automatically (scheduled scans)

You don't have to remember to run this. Because it's triggered by plain language, **any agent that can run on a schedule can run it for you** — Claude Code routines/cron, a scheduled task, or any agent framework that supports the skill format and a timer. Point the schedule at a prompt like *"scan my email for class action settlements from the last 30 days"* and it runs unattended.

Before you rely on that:

- **Weekly beats daily.** Notices trickle in and deadlines are weeks or months out, so a daily scan mostly produces empty reports. Once a week (or monthly) catches everything with far less noise.
- **Confirm the scheduled run can reach your mail.** The big one: it needs your email integration connected *and authorized in the environment where the schedule runs*. Interactive auth doesn't always carry into a background run — **do one manual run inside the scheduled setup first**, then automate.
- **Send yourself the result.** A report nobody opens is a scan that didn't happen — use your scheduler's completion notification (push/email).
- **Keep your record current.** Tell the skill what you've filed so each scheduled report stays focused on what's genuinely new.

## Fork it, make it yours

It's just one `SKILL.md` and a few reference guides — easy to fork and bend to your needs. **Please do.** Some ideas:

- **Add first-class support for your email provider.** It's already provider-adaptive (Step 4 in [`SKILL.md`](skills/class-action-finder/SKILL.md)); if you use Outlook, Proton, Fastmail, etc., tune the searches for it and send the improvement back.
- **Tweak the phishing scoring** in [`phishing-guide.md`](skills/class-action-finder/references/phishing-guide.md) — add administrator domains you trust, or adjust the weights.
- **Restyle the report.** [`report-template.md`](skills/class-action-finder/references/report-template.md) and Step 9 define the HTML.
- **Localize it** for settlements and claim-notice conventions in your country.

To contribute back: fork, make your change, and open a pull request — or just open an issue. No contribution is too small, and adapting it purely for yourself is completely fine too.
